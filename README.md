## About Me

CS Student at **JECRC University, Jaipur** -- passionate about building with **Python, TypeScript & AI**, open-source contributing, and crafting tools that make developers' lives easier.

I don't just use tech -- I dissect it, improve it, and share it. Whether it's pushing fixes to **matplotlib** and **Sphinx**, or building my own tools like **fenn** (ML framework) and **SkillOpt** (LLM skill optimizer) -- I'm in the trenches building.
